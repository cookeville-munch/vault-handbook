## 1. Foundational Engineering Concepts

### 1.1 Static vs Dynamic Load Analysis

- **Static Load**: Weight distribution when occupant is stationary (e.g., 60kg person suspended = 60kg force per anchor point)
- **Dynamic Load**: Forces generated during movement or acceleration (e.g., sudden jerk causing 1.5-2x static load)
- **Safety Factor**: Minimum 5:1 static factor, 3:1 dynamic factor for critical hardware

### 1.2 Force Distribution Mechanics
- **Load Path**: From anchor point → rope → harness → body (multi-stage stress points)
- **Vector Calculations**: Force angles affect tension (45° angle doubles effective load vs vertical pull)
- **Environmental Load Calculation**:
  - Wind resistance factor (0.3-0.8 multiplier based on orientation)
  - Temperature influence on material rigidity (10°C = 5% increase in modulus)
  - UV degradation multiplier for outdoor installations (0.1-0.3 per month exposure)

## 2. Hardware Engineering & Validation

### 2.1 Anchor Point Testing
- **Weasel Testing Protocol**:
  1. Apply 200% rated load
  2. Monitor for deformation/stress cracks
  3. Document failure mode and load threshold
- **Cross-Beam Requirements**:
  - 4x4 inch hardwood minimum for ceiling mounts
  - Diagonal bracing at 22° angles to resist torsion

### 2.2 Rope Material Science
- **Load Capacity Charts**:
  | Material                    | Static Rating | Dynamic Rating | Heat Resistance | Environmental Durability |
  |----------------------------|--------------|----------------|-----------------|--------------------------|
  | Natural Sisal              | 350kg        | 180kg          | Melts at 250°C  | 2-year outdoor warranty  |
  | Hemp                       | 400kg        | 200kg          | 275°C           | 1.5-year outdoor warranty |
  | High Modulus Polyethylene   | 500kg        | 250kg          | 300°C           | 3-year outdoor warranty  |
- **Elongation Limits**:
  - <2% ideal for suspension (exceeding causes dangerous sag)
  - <0.5% required for critical load-bearing applications (medical settings)

## 3. Suspension System Design Workshops

### 3.1 Position Calculations
- **Center of Gravity (CoG) Estimation**:
  - Weighted average of body segments (e.g., torso 40% weight, limbs 30%)
  - CoG offset determines torque requirements
- **Hip vs. Chest Suspension**:
  - Hip: Lower shear forces, better weight distribution
  - Chest: Higher nerve concentration, limiting load

### 3.2 Pressure Mapping Protocols
- **Force Distribution Algorithm**:
  - Identify pressure points (spine, keywords, shoulders)
  - Apply surface area multipliers (e.g., padded harness distributes 1.5x better)
  - **Live Monitoring Tools**:
  - Wireless strain gauges at anchor points
  - Pressure-sensitive mats under suspension points

## 4. Practical Engineering Exercises

### 4.1 Suspension Build Project
**Objective**: Construct a functional suspension system meeting safety standards
**Steps**:
1. Select 2 anchor points (ceiling joists)
2. Install webbing straps with 5,000N metal anchors
3. Build a 'Swedish Hitch' for adjustable ratchet tension
4. Create test harness using 30mm hemp rope
5. Conduct 3 load tests at 50%, 75%, and 100% rated capacity
6. Document inspection findings with photos

### 4.2 Failure Mode Analysis (FMEA) Workshop
- Group identifies potential failure points in design:
  - Rope fraying at specific angles
  - Hardware corrosion over time
  - User movement causing dynamic load spikes
  - Develop mitigation strategies for each scenario

## 5. Specialized Suspension Configurations

### 5.1 Advanced Positions
- **The 'Flaming Heart'**:
  - Dual-suspension with torso rotation
  - Requires synchronised 6-point anchoring
  - Load: 120kg dynamic peak
  - Added safety: automated secondary tether system
- **The 'Orbital Lock'**:

  - Requires redundant safety fetters

## 6. Safety Certification Workflow

### 6.1 Pre-Use Protocol
- **Visual Inspection Checklist**:
  - Rope: fuzzing, core exposure, color fading
  - Hardware: cracks, metal fatigue scoring
  - Webbing: UV degradation, seam integrity
- **Functional Test**:
  - Apply 150% rated load for 30 seconds
  - Verify movement resistance < 5°

### 6.2 Post-Use Evaluation
- **Condition Register**:
  - Rate degradation (1-5 scale)
  - Document any unusual noises or slack
  - **Retirement Threshold**:
  - Degrade >2 points on condition register
  - Visible hairline fractures in hardware
