# Community Resources Hub

## Resource Directory Structure

This directory contains curated resources for practitioners, communities, and participants. All subdirectories contain essential materials optimized for searchability and practical application.

## Core Resource Categories

1. **Link Directory** (`/link-directory/`) - Critical external resources for practitioners and users
2. **Toolkit Directory** (`/toolkit/`) - Downloadable templates and checklists
3. **Media Library** (`/media/`) - Public domain educational videos and guides
4. **Legal Resources** (`/legal/`) - Community governance templates and compliance materials
5. **Funding Directory** (`/funding/`) - Financial support opportunities
6. **Crisis Protocol Kits** (`/crisis/`) - Emergency response resources

## Resource Organization
All policies, templates, and guides follow strict structure:
- Version control numbering (vX.Y)
- A11y (accessible from screen readers)
- 2.1cm wide PDF margins for printability
- Standardized header/footer with resource type and last updated

## Quality Standards
- All documents audit-compliant
- Source citations included where applicable
- Must be reviewed for local legal compliance before distribution
